# java-lotto-precourse

---

## 입출력 처리

- 로또 구입 액수를 입력받는다.
  - `구매금액을 입력해주세요.`출력

- 당첨 번호를 입력받는다.
  - `당첨 번호를 입력해 주세요.`출력

- 보너스 번호를 입력받는다.
  - `보너스 번호를 입력해 주세요.`출력

- 발행한 로또 번호를 출력한다.
  - 첫 줄에 몇개의 로또를 구매했는지 출력
    - `8개를 구매했습니다.`
  - 한 줄에 로또 하나씩 출력
  - 한 줄에 6개의 번호를 오름차순으로 출력
    - `[8, 21, 23, 41, 42, 43] `
  
- 당첨내역을 출력한다.
  - 3 ~ 6개 일치, 5개+보너스볼 일치에 해당하는 당첨내역을 출력한다
    ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
- 수익율을 출력한다.
  - 수익율을 소수점 두자리에서 반올림해서 출력한다.
    - `총 수익률은 62.5%입니다.`
- 잘못된 입력이 들어온 상황에 대해 에러문구를 출력한다.
  - 에러문구는 `[ERROR]` 로 시작한다.
    - `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
  - 해당 입력은 에러문구 출력 후 다시 입력받는다.

## 입력 검증

- 입력받은 액수를 검증한다.
  - 숫자로 이루어져 있는가
  - 1000단위로 나누어 떨어지는가

- 입력받은 당첨번호를 검증한다.
  - 쉼표를 기준으로 6개의 숫자를 입력받았는가
  - 각 숫자가 1~45 사이의 숫자인가
  - 중복되는 숫자가 존재하지 않는가

- 입력받은 보너스 번호에 대해 검증한다.
  - 숫자로 이루어져 있는가
  - 1 ~ 45 사이의 숫자인가
  - 이전에 입력받은 당첨번호와 중복되지 않는가

## 메인 로직 처리

- 입력받은 액수만큼의 로또를 발행한다.
  - 발행된 로또는 1 ~ 45사이의 숫자 6개로 이루어져 있으며 하나의 로또 안에서 숫자가 중복되어선 안된다.

- 발행된 로또와 입력받은 당첨번호, 보너스 번호를 통해 당첨결과를 계산한다.

- 구입금액과 당첨금액을 바탕으로 수익율을 계산한다.
  - 수익율은 소숫점 아래 2자리에서 반올림한다.
